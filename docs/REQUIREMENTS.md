# Requirements

Notes for the map data. Renderer requirements live with the mesh-renderer work and are not part of this file's data section.

## Map snapshot

The base snapshot is the current OpenStreetMap extract (`data/osm/kherson.json.gz`). Buildings and tree rows mapped after January 2022 stay: they were missing from the old extract, not missing from the city.

A committed restoration table (`data/osm/restoration.json`) undoes war effects only. It is generated by `npm run build-restoration` from Geofabrik `ukraine-220101` (OSM as of **2022-01-01**, the reference clip under `data/osm/reference/`). Each row is an OSM id, a field, the pre-war value, a source and version, and a reason. `data/osm/restoration-overrides.json` replaces rows by hand. The bake applies the table; it does not recompute it, and it does not call Overpass.

- Damage and lifecycle tags that were not already set on 2022-01-01 are reverted (`building=ruins|destroyed|damaged|collapsed`, `abandoned:*`, `demolished:*`, `was:*`, `disused:*`, and the same for `ruins` / `destroyed`). A footprint mapped only later and tagged ruins is kept as `building=yes`.
- Building ways that existed in the reference and are absent now are re-added, unless at least half their nodes already belong to a current building.
- Street names on ways that exist in both extracts return to the reference. The current name is kept on `old_name` so search still finds it.
- `military`, checkpoints, barricades and `memorial=war_memorial` objects that are not in the reference are dropped. An ordinary monument mapped later is not.

Deploys bake the committed base plus the table. If the base file is missing, bake and fetch may download the GitHub release `osm-base` and check `SHA256SUMS`. Publishing that release is a manual owner step. A normal push does not create it.

## Antonivskyi road bridge

The bridge (Wikidata Q4067525) stands in the Dnipro just outside city relation 2175078. Owner decision: include the pre-war, intact road bridge.

- The restoration puts the pre-war node list back on the carriageways and removes `ruins` / `destroyed`. The post-war `highway=proposed` duplicate is dropped.
- Do not widen the city polygon to the left bank or to Antonivka.
- Stamp a corridor 30 m around the carriageways and the bridge outline, plus 450 m of trunk approach at each end (`tools/bake/bridge-corridor.ts`).
- The railway Antonivskyi bridge (Wikidata Q4067523) is a different structure and is not part of the corridor.
- The world rectangle's east edge is 32.73 so the span (centreline near 32.720) fits in the grid. West and north stay put, so existing `x`/`z` poses do not move.
