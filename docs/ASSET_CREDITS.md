# Asset credits

The PBR materials under `public/assets/materials/` are **CC0 1.0** from [ambientCG](https://ambientcg.com/). CC0 requires no attribution; the sources are credited here anyway, and `data/materials.json` is the machine-readable manifest the fetch and pack tools read. Each layer is packed without alpha as `<name>_a.webp` (albedo with ambient occlusion baked in, then normalised, tinted and desaturated as configured) and `<name>_n.webp` (normal x/y in R/G and roughness in B); alpha is avoided because a 2D-canvas decode premultiplies it and corrupts the data channels. The list below is generated by `npm run pack-materials`; do not edit it by hand.

Facade photos (CC0 / CC-BY / CC-BY-SA / public domain, dated before 24 February 2022) will get their own section below with author, source URL, date and licence (Constitution 8.3).
